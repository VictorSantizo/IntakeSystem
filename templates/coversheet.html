★ How to use
  1. Print a fresh sheet for each folder (or photocopy a stack of blanks).
  2. Write the received date in the big boxes above.
  3. Lay it on top of that folder's mail and scan the whole pile.
  4. The system reads this sheet and stamps that date on every file behind it — no typing.
  5. Wrong date later? Fix it in Review with the date picker (it'll offer to fix the whole batch).
